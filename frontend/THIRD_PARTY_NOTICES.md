# Componentes de código aberto

Esta prévia utiliza componentes de terceiros sob suas respectivas licenças. A relação abaixo indica as fontes oficiais das licenças; os pacotes e seus avisos são obtidos pelas versões fixadas no package-lock.json.

- React e React DOM — MIT — https://github.com/facebook/react/blob/main/LICENSE
- React Router — MIT — https://github.com/remix-run/react-router/blob/main/LICENSE.md
- Tailwind CSS — MIT — https://github.com/tailwindlabs/tailwindcss/blob/main/LICENSE
- Recharts — MIT — https://github.com/recharts/recharts/blob/main/LICENSE
- Lucide — ISC — https://lucide.dev/license
- Decimal.js Light — MIT — https://github.com/MikeMcl/decimal.js-light/blob/master/LICENCE.md
- Vite — MIT — https://github.com/vitejs/vite/blob/main/LICENSE

Para preservar os avisos ao distribuir a prévia, os textos de licença instalados são reunidos em `public/third-party-licenses.txt`.
