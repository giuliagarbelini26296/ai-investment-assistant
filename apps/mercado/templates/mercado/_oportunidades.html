Como o score é calculado
  • T1 Perto da mínima de 52 semanas (12): 12 pontos com o preço até 5% acima da mínima; 0 a partir de 40%; linear entre os dois. Exige ao menos 6 meses de candles.
  • T2 RSI de 14 sessões (8): ≤ 30 = 8; ≤ 40 = 5; ≤ 55 = 2; acima = 0.
  • T3 Tendência (15): preço acima da média de 200 sessões = 8; histograma do MACD (12, 26, 9) positivo = 7, negativo mas subindo = 4.
  • A1 Potencial até o preço-alvo médio (25): 25 a partir de +30%; 0 se ≤ 0; linear. Preço-alvo é projeção de analistas (horizonte típico de 12 meses).
  • A2 Consenso (15): 15 com ≥ 85% de recomendações de compra; 0 com ≤ 40%; −5 se ≥ 20% recomendam venda. Exige ao menos 5 analistas.
  • F1 Margem líquida (8): > 10% = 8; > 0 = 5. F2 ROE (8): ≥ 20% = 8; ≥ 10% = 5; > 0 = 2. F3 P/L (9): até 20 = 9; até 30 = 6; até 45 = 3.
  • Risco: volatilidade anualizada de 90 sessões < 25% baixo, < 45% médio, senão alto; sobe um nível com resultado em ≤ 7 dias, tendência de baixa, queda ≥ 15% na semana, ≥ 30% de recomendações de venda ou volatilidade recente acima de 1,5× a de 6 meses.
  • Perspectiva: "médio/longo prazo" quando analistas/fundamentos pesaram mais; "curto prazo" quando pesaram os sinais técnicos.
